# Portfólio — Gustavo Nascimento

Landing page estática criada para publicação no GitHub Pages.

## Domínio escolhido

O endereço definitivo será `portfoliogustavoeditor.com.br`.

Neste primeiro teste, publique somente pelo endereço gratuito do GitHub Pages. Não adicione um arquivo `CNAME` e não altere o DNS ainda. Depois que a página estiver aprovada, o domínio será conectado ao mesmo repositório.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `portfolio-lp`.
2. Envie **o conteúdo da pasta `dist`** para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.
6. A página ficará disponível em `https://ngustavo28-eng.github.io/portfolio-lp/`.

## Alterar conteúdo

- Textos e links: `dist/index.html`
- Cores e layout: `dist/styles.css`
- Interações: `dist/script.js`
